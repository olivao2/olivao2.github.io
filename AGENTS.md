# Portafolio audiovisual

Proyecto independiente de Figma: React, TypeScript, Vite y Tailwind CSS v4. Usar npm y package-lock.json. No hay servidor preiniciado: npm run dev abre el puerto 5173. npm run build genera dist/.

Preservar el diseño en src/index.css. Datos en src/data.ts, tarifas en src/pricing.ts, modales en src/components/. Verificar npm run typecheck, npm run lint, npm test y npm run build. No simular envíos, contactos, tarifas ni pagos. Mantener null para importes sin configurar. No incluir secretos en el cliente.
